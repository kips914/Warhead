# Warhead v0.6 — анимации, настройки эффектов и оптимизация

## Новое
- Бомбардировщик выполняет плавный овальный маршрут с изменением высоты. В качестве лёгкой основы по-прежнему используется ванильный фантом, поэтому его крылья анимируются штатной анимацией Minecraft; отдельный самолётный рендерер пока не подключён.
- Бомбардировщик сбрасывает TNT через заданный интервал, учитывая скорость полёта; включены звуки сброса/запуска.
- Ракета получает дымный след и огненные частицы, а при запуске воспроизводится звук.
- Добавлена общая конфигурация `config/warhead-common.toml` (создаётся Forge автоматически):
  - `effectsLevel`: 0 — минимум, 1 — низкий, 2 — обычный, 3 — высокий;
  - `soundEffects`: звуковые эффекты Warhead;
  - `cameraShake`: тряска камеры;
  - `bomberDropInterval`: интервал сброса бомб в тиках (20 тиков = 1 секунда);
  - `maxDebrisPerBlast`: ограничение числа физических обломков на один взрыв.
- Для производительности уменьшено количество частиц на низких настройках и ограничено число сущностей-обломков, создаваемых одним взрывом. Логика взрывной волны продолжает обрабатывать клетки порциями с временным бюджетом на тик.

## Сборка
Minecraft 1.20.1 / Forge 47.2.0 / JDK 17 / Gradle 8.1.1. Выполнить `gradle build`; JAR появится в `build/libs/`. В текущей среде сборка Java не подтверждена: Gradle не установлен.

## Ограничения
- Бомбардировщик всё ещё основан на Phantom, а не на отдельной 3D-модели самолёта. Движение и штатная анимация крыльев включены.
- Взрывы и обломки остаются игровым приближением. Настройки частиц/звука и лимит обломков управляют нагрузкой, но не гарантируют отсутствие просадок на любом компьютере.
